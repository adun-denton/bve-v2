# BVE V2 working instructions

Read README.md and docs/WHY.md, ARCHITECTURE.md, CONTRACTS.md before changing software. Preserve role/function/job/executor meanings. Build the organization first; assign intelligence afterward.

Routine bounded work proceeds under the user's existing intent. Do not add permission ceremonies. Human review submission and explicit design acceptance remain distinct. Never spend image calls, switch to a charged provider, or rerun an uncertain attempt without applicable existing scope.

Keep private runtime roots outside source control. Do not import, migrate, modify or discover legacy user runtime data by default. Public assets and evidence must be authored fixtures. Do not publish tokens or local adapter secrets.

Enforce ownership through narrow interfaces and validated transitions, not caller-provided role labels. Conductor commissions creative specifications; Generator dispatches; Butler deterministically validates/reconciles; humans review/accept. No direct executor writes to authority.

Test the full cycle, recovery and prohibited transitions. Tests/fixtures establish no real host capability or human acceptance. Record those limits candidly. Keep dependencies small. No general RBAC, agent framework, embedded chat or Foreman.
