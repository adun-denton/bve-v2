# PNG preview and metadata read service

`Kernel.artifactMedia(token,artifactRef)` derives a navigation PNG and bounded structured metadata from exactly productId,artifactId,version,sha256,width,height. GET `/api/original?view=media&productId=…&id=…&version=…&sha256=…&width=…&height=…` exposes this internal JSON view. Keys are closed/unique, integers canonical positive decimal, query<=1024 UTF-8 bytes. Default `/api/original?id=…` and `Kernel.original` retain exact original bytes and existing role behavior. No arbitrary path/URL or binary intake is accepted.

Media scope requires actual human/current Conductor credentials, with bound Conductor restricted to its product. Butler/workers/assignment-only bearers/role labels cannot authorize it. Exact artifact fields and committed import declaration/origin links are checked before processing and on cache hits. Identity409,auth403,unknown artifact404,malformed query400 remain separate from a200 media-unavailable view. JSON responses are no-store/nosniff with stable codes and no private exception paths.

`bve.png-media.v1` binds the frozen artifact-ref and actual importId/importRecord or recorded produced job/iteration/delivery IDs (null means absent legacy data). derivativeId is SHA256 of sorted-key JSON plus LF for `{schemaVersion:'bve.preview-key.v1',sourceBinding,profile}`. Actual PNG/pixel hashes remain separate from original SHA256; derivative IDs are never artifact references. No artifact/job/staff/attempt/approval/domain revision or persistent cache is created. Original bytes and provenance remain immutable.

Fixed profile: `bve-png-nearest-stored.v1`, maxEdge384, no upscale/crop, nearest-center-integer, stored-raster orientation, unmanaged samples, straight alpha, RGBA8/filter0/zlib stored-block output. Let `D=max(width,height,384)`; output dimensions are `max(1,floor(dimension*384/D))`. Each output coordinate samples `floor((2*coordinate+1)*sourceDimension/(2*outputDimension))`. Aspect rounding can change by one output pixel; thin detail may alias. Output has only IHDR, generated BVE-Derivative lineage tEXt, IDAT and IEND, without copied source metadata or timestamps.

Only static8-bit noninterlaced gray/RGB/gray-alpha/RGBA with filters0..4 are eligible. Gray/RGB tRNS uses low8-bit samples, one correctly ordered chunk after optional PLTE/before IDAT. Straight alpha and hidden RGB are preserved; no flattening. New-view palette/transparency/animation/depth/interlace/chunk restrictions never tighten default original acceptance. Input<=16MP/24MiB; matched>16MP references decline PIXEL_POLICY before inflate/cache, without changing experimental original permissions or IMG20 status.

`bve.png-metadata.v1` reports measured IHDR, transparency, stored orientation, unknown color fidelity and numeric gAMA/sRGB/cHRM/pHYs declarations. Field states absent/valid/invalid are distinct; absent/invalid values are null. Valid checks only length/range/multiplicity/order, including before optional PLTE for interpreted color fields and before IDAT for pHYs. It certifies no profile/gamut/DPI/physical size. EXIF orientation stays null/uninterpreted; no autorotate or pHYs stretch. No ICC/gamma/HDR conversion or color-managed/print fidelity claim.

Five private descriptors (iCCP,eXIf,tEXt,zTXt,iTXt) expose count/encoded-byte totals and SHA256 of source-order `(uint32BE length || encoded payload)` frames. No embedded names/text/GPS/EXIF/profile payload is exposed or inflated. Other ancillary types expose aggregate count/bytes only. Inspection<=4096 chunks/24MiB,metadata<=16KiB,PNG<=600000bytes,base64<=800000chars,response<=1MiB. Metadata warnings are deterministic/sorted; CACHE_REBUILT occurs only in outer transient warnings, never hashed metadata/key/PNG.

Private memory cache:<=16 complete ready entries/8MiB retained serialized payloads. One JSON string includes base64; key/checksum representations are also counted. No duplicate PNG/base64 representation is retained. At capacity return uncached. Hits reauthorize and verify current original/provenance plus cached key/metadata/PNG/pixel hashes. Missing/corrupt originals never authorize stale previews. A corrupt disposable entry can rebuild deterministically once; return copies are defensive. Object/engine overhead and transient buffers are not a target-memory certification.

Eligible misses reuse one bounded validated inflate buffer, unfiltered in place, and sample directly without a second full original RGBA. Synchronous finite work does not establish<=50ms responsiveness or continuous peak/main-child coverage. Authored observations retain those limitations.

No root marker/SQL schema/record kind/BLOB/domain file/backup-format change. Close/restart clears only cache. Existing complete combined backup preserves authoritative originals/provenance; separate verified restore regenerates identical derivative/key/metadata hashes. Cache cannot complete a backup with missing originals. Preserve heads, failed roots, private keys and evidence under existing procedures; no live migration/rollback/installation is implied.
