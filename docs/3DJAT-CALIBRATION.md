# Calibration through the existing boards

In a product's Operations list, select a retained photo, choose an adopted creative operation and use **Test template**. Select three source-verified revisions and common settings. Saving records a bounded comparison request; the configured Conductor still commissions the existing round and workers. No generator starts from discovery, review, revision or promotion.

Compare the retained results, record comments and select a treatment. **Revise selected treatment and compare again** writes an explicit revision through the existing template writer and creates a linked comparison with the same common photo, intent, Brand, settings, seed and declared executor context. The other two revisions stay fixed. Each treatment opens the existing round board for annotations; source branching, channel approvals and conventional operations remain independent.

**Promote selected revision for Instagram artistic only** is a separate human command through the file-owned template writer and its CAS/grant/source fences. It references the committed SQLite experiment receipt and exact verified outputs. Experiment completion never changes file-owned adoption. Restart between completion and promotion remains awaiting approval. Replaying the original promotion packet recovers its receipt; changing that packet conflicts. A light-product adjustment records a proposal without changing the domain head or any other scope.

Contract validity, operational outcome, visual testing and human adoption are separate statuses. A failed or unavailable generator has no comparison images and cannot be promoted. Authored fixture pixels/callbacks establish protocol behavior only; they do not establish real contrast quality, native operation, Mahsa's judgment or intended-machine acceptance.

The browser retains exact uncertain commands for explicit reconciliation. A proven no-effect rejection requires a current reread and acknowledgement before a fresh action. Controls from an older product/render cannot submit current decisions. Technical lineage is optional inspection, not required input.

Storage remains the existing SQLite records/receipts and domain-file writer. Ordinary 16MP/24MiB limits, existing staffing/once-only boundaries and the opt-in 20MP experiment remain unchanged. This candidate requires the current calibration-aware reader; it introduces no production migration or setup authorization.

    node --test test/j11-calibration.test.mjs test/j11-client-actions.test.mjs test/j11-http-controls.test.mjs

A browser denial must remain reported; direct-handler tests do not replace browser evidence.
